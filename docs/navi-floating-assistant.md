## Right rail — 2026-10-22

Owner direction (selected base `output/ohmyfinance-navi-right-rail-20261021/navi/base`): the character sits in the gutter between the content and the browser's right edge instead of over the fields; she can be shrunk, the maximum being the 2026-10-20 size; the dialogue opens as a tall rail on the right rather than over the page; she disappears while the chat is open and the circle portrait appears in the chat header; she moves occasionally.

- `layouts/default.vue` puts the contract on its root: `navi-layout`, `navi-size-small|medium|large` from the assistant store, `navi-open` while the chat is open, `navi-off` while locked or signed out. `<main>` carries `navi-host`. At ≥768px the main column reserves on its right `1.5rem + character width + edge gap` while closed, `1.5rem + rail width + edge gap` while open, and 1.5rem when off; the page-end bottom padding remains only below 768px. The dock no longer centres on the 99rem frame: it sits at the edge gap (2rem desktop, 1rem below 768px) and the page makes the gutter.
- Tokens live on `.navi-layout` instead of `:root`: `--navi-size` 18rem / 11rem / 6rem (large / medium / small; 13rem / 9rem / 6rem below 768px), `--navi-launcher-size:min(var(--navi-size),40dvh)`, `--navi-chat-width` 22rem (20rem under 1400px). Large is today's maximum; nothing grows past it.
- Open at ≥768px (not compact): the dock becomes a fixed rail from the measured header clearance + .875rem down to the bottom gap, `--navi-chat-width` wide; the conversation fills it (`inset:0`). Compact (short) viewports keep their 2026-10-20 geometry. While open the launcher and the size control are `display:none` at every width; on close they return at the chosen size in the same tick, so Escape/minimize still lands focus on the launcher. The header portrait is `NaviAvatar md` (the 2.75rem film circle) on normal heights and `sm` on compact; the closed launcher stays the transparent, uncircled PNG.
- Size control (closed only): `[data-navi-size-toggle]` opens `[data-navi-size-menu]` with 小 / 中 / 大（今のサイズ・最大）; a pick calls `assistant.resize` and closes the menu; Escape closes the menu and returns focus to its toggle before the existing Escape branches. `stores/assistant.ts` adds `size` and `resize()`; `identify()` restores the token from browser `localStorage` key `omf-navi-size:<ownerId>` (one of three tokens, anything else is large). No server field, no other data.
- Motion: a 45 s timer sets `navi-character-motion` on the character only while closed, on a visible tab, without reduced motion; the class runs `navi-greet` (2.6 s, ≤3px / ≤1.3°, transform only, so neither the dock nor the content moves) and the character's `animationend` clears it. `prefers-reduced-motion: reduce` sets `animation:none`. The timer is cleared on unmount. No reply-triggered motion: nothing tells the closed character about a reply (status/unread while closed is a separate server contract, not shipped).
- Unchanged: `NaviAvatar.vue`, `AssistantConversation.vue`, `PurchaseChat.vue`, server, worker, model and action code; z-order (title rows 10, Navi 20, header 30, drawer 40, modals 50).

Current status since 2026-10-23: the closed character now shows the server status of the conversation it opens (new reply / queued / working / interrupted / reconnect / failed / unknown; "working" only while the job's own native deadline is ahead), as a small static pill inside the launcher button's own box with the conversation named in its accessible label; nothing when idle, hidden while open, no added motion. The transcripts acknowledge a reply only when its live text is visible in the open chat, and keep an older reader's position with a "新しい回答 ↓" jump.
