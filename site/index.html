現在の提供方式

現在の版では、当社が管理するサーバーでサービスが動作し、財務データはそのサーバーに保存されます。

準備中

お客様のパソコンにインストールして使う版を準備中です。

現在の版では、本サービスは当社が管理するサーバーで動作し、財務データと各サービスの認証情報はそのサーバーに保存されます。お客様のパソコンにインストールして使う版を準備中です。提供開始後は、これらはお客様のパソコンに保存されます。インストール版（準備中）では、当社のサーバーに置くのは、このサイト、インストーラーと更新ファイルの配布、アカウントとご契約の管理、端末の接続状態、マスクした診断情報、そしてお客様が選んだ場合の暗号化バックアップの予定です。現在のバックアップは、本サービスが動作するサーバー上のファイルとして保存され、暗号化されていません。詳しくはプライバシーポリシーをご覧ください。

Google アカウントの利用について

請求書の送付のために、お客様の会社は、ご自身の Google アカウントの Gmail を OhMyFinance に接続できます。接続は任意です。OhMyFinance は、接続した Gmail アドレスの確認と、お客様が作成した請求書メールを、お客様の Gmail から「お客様に代わって送信」することだけに使います。更新トークンは暗号化して、本サービスが動作するサーバーに保存します。利用する権限と取り扱いの詳細はプライバシーポリシーに記載しています。

OhMyFinance について

OhMyFinance（オーマイファイナンス）は、会計、請求書の作成と送付、銀行・カードの明細取込、そして AI アシスタントによる記帳の補助（提供準備中）を一つにまとめた、事業者向けのアプリです。

English summary

OhMyFinance is an accounting and invoicing application for businesses. In the current version the service runs on a server managed by the operator, and financial data is stored on that server; a version installed on the customer's own computer is in preparation (準備中) and this page will be updated when it launches. A company may optionally connect its own Gmail account so that OhMyFinance can send the invoice emails the user composes from that account; the refresh token is encrypted and stored on the server that runs the service. See the privacy policy.
